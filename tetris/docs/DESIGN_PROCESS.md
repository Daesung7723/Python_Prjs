# 테트리스 게임 개발 - 소프트웨어 설계 프로세스

## 개요

키보드 방향키와 스페이스바를 이용한 테트리스 게임을 개발하기 위한 설계 프로세스 문서입니다.

---

## 단계별 설계 프로세스

### 1단계: 요구사항 분석 (Requirements Analysis)

**목표**: 시스템이 무엇을 해야 하는지 정의

- [x] 기능 요구사항 정의
  - 게임 기본 규칙 (테트로미노 종류, 이동, 회전, 낙하)
  - 키보드 입력 정의 (←→ 이동, ↑ 회전, ↓ 빠른낙하, Space 즉시낙하)
  - 점수 및 레벨 시스템
  - 줄 완성 및 삭제 규칙
  - 게임 오버 조건
- [x] 비기능 요구사항 정의
  - 응답성 (키 입력 지연 최소화)
  - 프레임 속도 목표
  - 실행 환경 (Python 터미널 또는 GUI)

**산출물**: `requirements.md`

---

### 2단계: 시스템 설계 (System Design)

**목표**: 전체 아키텍처와 모듈 구조 설계

- [x] 아키텍처 패턴 선택 (MVC 패턴 적용)
  - **Model**: 게임 상태, 보드, 테트로미노 데이터
  - **View**: 화면 렌더링 (터미널 또는 pygame)
  - **Controller**: 키보드 입력 처리, 게임 루프
- [x] 모듈 분리
  - `game.py` — 메인 게임 루프
  - `game_state.py` — 게임 상태 Enum (구현 중 분리)
  - `board.py` — 게임 보드 로직
  - `tetromino.py` — 테트로미노 정의 및 동작
  - `renderer.py` — 화면 출력
  - `input_handler.py` — 키보드 입력
  - `score.py` — 점수 및 레벨 관리
- [x] 기술 스택 결정
  - 렌더링 라이브러리 선택 (pygame vs curses vs tkinter)

**산출물**: `system_design.md`

---

### 3단계: 상세 설계 (Detailed Design)

**목표**: 각 모듈의 클래스, 함수, 데이터 구조 설계

- [x] 클래스 다이어그램 작성
  - `Board` 클래스 — 10×20 그리드, 충돌 감지, 줄 삭제
  - `Tetromino` 클래스 — 7가지 블록(I, O, T, S, Z, J, L), 회전 행렬
  - `Game` 클래스 — 게임 상태 머신 (시작/진행/일시정지/종료)
  - `Renderer` 클래스 — 보드 출력, UI 요소
  - `ScoreManager` 클래스 — 점수 계산, 레벨업 규칙
- [x] 데이터 구조 정의
  - 보드: 2D 리스트 (0=빈칸, 1~7=블록색상)
  - 테트로미노 회전 상태: 4×4 행렬 배열
  - 게임 상태 Enum
- [x] 알고리즘 설계
  - 충돌 감지 알고리즘
  - 줄 완성 판별 및 삭제 알고리즘
  - 블록 회전 알고리즘 (단순 회전 취소 방식 채택, SRS 미적용)
  - 낙하 속도 레벨 곡선

**산출물**: `detailed_design.md`

---

### 4단계: 구현 (Implementation)

**목표**: 설계 문서를 기반으로 코드 작성

- [x] 개발 환경 설정
  - 가상환경 생성 및 의존성 설치
  - 프로젝트 디렉터리 구조 생성
- [x] 핵심 모듈 구현 순서
  1. `tetromino.py` — 블록 데이터 및 회전
  2. `board.py` — 보드 로직 및 충돌 감지
  3. `score.py` — 점수 계산
  4. `renderer.py` — 화면 렌더링
  5. `input_handler.py` — 키보드 입력
  6. `game_state.py` — 게임 상태 Enum (설계 대비 추가 분리)
  7. `game.py` — 게임 루프 통합
- [x] 코딩 규칙 적용 (PEP 8)

**산출물**: 소스코드 파일들

---

### 5단계: 테스트 (Testing)

**목표**: 각 모듈 및 전체 시스템 검증

- [x] 단위 테스트 (Unit Test)
  - 테트로미노 회전 정확성
  - 충돌 감지 로직
  - 줄 삭제 및 점수 계산
- [x] 통합 테스트 (Integration Test)
  - 게임 루프와 입력 처리 연동
  - 렌더링과 게임 상태 동기화
- [x] 수동 플레이 테스트
  - 키 응답성 확인
  - 게임 오버 및 레벨업 동작 확인
  - 엣지 케이스 (보드 경계, 스택 상단 도달)

**산출물**: `tests/` 디렉터리, 테스트 결과 보고서
